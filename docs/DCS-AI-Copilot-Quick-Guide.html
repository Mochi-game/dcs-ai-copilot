DCS AI COPILOT — WHAT DO I SAY WHEN?

EAT → CROSSING → COMMENCING

1Marshal gives EAT

SAY: “EAT TWO ONE”

Stores the next :21. Full-time example: “EAT ONE FOUR TWO ONE”.

2Cross marshal fix

SAY: “CROSSING”

Records now and calculates the hold to EAT. Say it again at a later crossing to replan.

3Leave the hold

SAY: “COMMENCING”

Starts approach guidance. The clock reaching EAT does not commence automatically.

4Check the plan

SAY: “CASE THREE STATUS”

Opens the CASE III page without changing the plan.

Marshal assignment example

SAY: “CASE THREE, MARSHAL TWO ZERO ZERO TWO TWO, ANGELS SEVEN, TIME THREE TWO, BUTTON ONE FIVE, FINAL BEARING ONE SEVEN ZERO, TACAN SEVEN TWO X, ICLS ONE.”

Available labeled fields: radial/marshal, DME, angels, time/EAT, button, final bearing/FB, TACAN and ICLS. Fields may be spoken separately. Invalid fields are rejected rather than partially applied.

Time source

  • MISSION: DCS-BIOS mission start + model time. It follows simulation time and freezes when DCS is paused; no local extrapolation.
  • PC: used until mission-time data arrives.
  • MANUAL: with PC source only, “SYNC CLOCK HHMM” offsets CASE III without changing Windows time.
  • If mission packets stop, the last mission reading remains selected and is marked not live; Copilot does not silently switch to PC time.

MICROPHONE & TROUBLESHOOTING

Select the input

  1. Start DCS AI Copilot and open its dashboard.
  2. In VOICE, select the desired physical microphone.
  3. Press Use microphone.
  4. Hold PTT and verify RECORDING.
  5. Say “NOTE MICROPHONE TEST”, release, and check LAST TRANSCRIPT.

The selection is saved by exact device name + Windows host API. It does not alter Windows, SRS, Discord, DCS or VR audio settings.

Which duplicate should I choose?

MME, DirectSound, WASAPI and WDM-KS can be different Windows paths to the same physical microphone. There is no universal requirement to use MME. Choose the correct physical name, test it, and keep the entry that records reliably. A webcam is a common accidental default.
